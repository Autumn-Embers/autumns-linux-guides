How To Install Linux

PREPARATION


First, you will need to download Ventoy on your system.

I will list instructions on getting ventoy running on each os.

On Windows, click here to go to the ventoy download page, Then download the windows version of ventoy, Then extract the file, Then run ventoy.

On Pacman/Arch based systems, open terminal and type sudo pacman -S paru if you don't already have paru, Then type sudo paru -S ventoy, Then run ventoy.

On Red Hat/Fedora systems, open terminal and type sudo dnf copr enable karlisk/ventoy Then type sudo dnf install ventoy, Then run ventoy.

On Nixos, (Note this will only work if you allowed unfree software when you installed Nixos), open terminal and type nix-shell -p ventoy-full Then type sudo ventoy-web Then it will give you a link, copy the link, then open your browser and paste it into the search bar, Then it will be running ventoy in your browser.

On Ubuntu based systems, click here to go to the sourceforge ventoy download page, then download the linux.tar.gz file then in terminal type cd Downloads Then type tar -xzvf ventoy-(version number here)-linux.tar.gz must match the version you downloaded for example ventoy-1.1.17-linux.tar.gz Then type cd ventoy-(version number) Then type ls Then type sudo ./VentoyWeb.sh Then copy the it will give you a link to copy, after copying the link open your browser and paste it into the search bar, Then you will have ventoy running in the browser.

Next, install ventoy to an empty usb drive, by selecting which usb drive you want to use, and then clicking install.

Once thats done, install an iso file for the distribution/Distro of linux you want. See my recommendations here.

Lastly, put the linux iso file you just downloaded onto the ventoy usb drive.

INSTALLATION


First, restart your pc and enter the boot options with the button instructed to be pressed on the bios startup screen common ones are F2, F12, and DELETE.

This is my startup screen for example, so i would hit F12 for boot options.


Then, select the VENTOY PARTITION 2 in the boot options.

Here is mine as an example, yours will be the name of the usb drive you installed ventoy on and partition 2.


Then, select the linux iso for the distribution/Distro you chose on the ventoy boot loader screen.

Here is an example for what that should look like.


Now, depending on what Distro you chose you will either go straight to the installer, or load up into the installers desktop environment, if you load up into the installers environment, then all you have to do is open the installer, which is usually on the desktop.

(These steps could be out of order because it's not the same for every Distro's installer.)

Now in the installer, you will be prompted to select some basic configuration stuff like your keyboard layout and timezone/location.

Then, you will be prompted to create users or just a user, all you will have to do is type in a name, username and password.

Then, if prompted to, select the desktop environment you want to use, CINNAMON and PLASMA are usually the best for beginners, and Gnome is good too, (not all installers will let you choose which desktop environment you want to use.)

Then you will be prompted to select and format the drive you are going to install the os on, (NOTE THAT ALL DATA ON THE DRIVE/PARTITION YOU SELECT WILL BE ERASED), unless you choose to install alongside an existing os on the same drive in which case you will probably have to partition the drive manually.

Lastly, follow the rest of the steps on the setup screen if there are any, then wait for the install to be done, once its done installing restart and remove the usb drive.

MY OS Recommendations


Linux Mint
For general use, and it's good to get you into linux as a first distro to try as it's easier to swap to from Windows then other Distros, however don't expect it to just be the same thing as Windows.

Cachyos for gaming.

Also Pikaos, Endeavouros, and Nixos are great options too.

I would strongly recommend against installing Arch linux if you are a beginner as it is much more complicated to install, because you have to download the desktop environment and all the other essential stuff your os needs to run via the terminal on the arch installer, now that's just for Arch linux on it's own though, however arch linux based Distro's are some of the best options, because a lot of them act as an installer for Arch linux without all the complicated stuff.
If you want to install Arch linux, you can use my Arch linux guide, link will be at the bottom of the page.
