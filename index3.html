How To Setup Linux

Commands


On linux there are many different commands you can use in terminal and you will wanna learn the basics of using it, especially for installing updates and downloading software/apps.

So first off, it will depend what Distro you chose to use, but they all have different commands.

We'll start with download and system update commands.

On pacman/arch linux Distro's, in the terminal type the following for system wide updates (this includes updating apps and software) sudo pacman -Syu
Also on pacman/arch Distro's you can type sudo -S (name of application/software you want to download) to download stuff straight from the terminal.

On debian/ubuntu Distro's open up the terminal, then type sudo apt update that updates the package list, and after that command type sudo apt upgrade to do a system wide update (that includes applications/software)
You can also do sudo apt install (name of app/software you want to download) to download stuff from terminal.

On rpm/fedora Distro's open terminal, then type sudo dnf upgrade --refresh to update your system and apps, then to update the os version lookup fedora latest os version, then you can update the os with sudo dnf system-upgrade download --releasever=(releasenumber)
Also you can use the command sudo yum download in (package name) to download apps/software.

On nix/nixos you will use sudo nixos-rebuild switch --upgrade to update the system, and use sudo nix-env -iA [package name] to install applications/software,you should do, sudo nano /etc/nixos/nix.configuration then find the packages list, and type in the package name of what you want to install, then save the file, and type cd /etc/nixos then sudo nixos-rebuild switch

So thats download commands done.

Themes And GENERAL Configuration


Ok, so most distributions i've tested have quick settings on the task bar, if you open that you should get taken straight to themes, you should be able to change the theme and wallpaper from there.

You can find most of the settings you will need through quick settings on the side menu, like display configuration, mouse sensetivity and keyboard layout.

If you are using a controller, you will want to turn off mouse and keyboard input, in the controller settings.

To turn off auto screen dimming and show logout screen go to power management in the quick settings and you can change them in there.

AND DONE

So that's pretty much it for setting up linux, on a lot of modern Distro's the setup process is pretty simple.
